# Лендинг барбершопа с заявками в Telegram и Google Таблицу

Одностраничный сайт: первый экран, прайс, форма записи, контакты.
Заявка с формы сразу приходит владельцу в Telegram и записывается строкой в Google Таблицу.
Сервер не нужен: сайт бесплатно размещается на GitHub Pages, заявки принимает Google Apps Script.

## Что внутри
- `index.html` — весь сайт в одном файле (вёрстка, стили, скрипт)
- `apps_script.gs` — приём заявок: таблица + сообщение в Telegram (токен бота хранится у Google, на сайте его не видно)

## Возможности
- Адаптивная вёрстка: телефон, планшет, компьютер
- Прайс из списка в начале скрипта — цены меняются в одном месте
- Проверка имени и телефона, номер приводится к виду +7 900 123-45-67
- Защита от спам-ботов (невидимое поле-ловушка)
- Демо-режим: пока форма не подключена, заявки только выводятся в консоль

## Подключение формы
1. Google Таблица → Расширения → Apps Script → вставить `apps_script.gs`, вписать токен бота и свой Telegram ID
2. Начать развертывание → Веб-приложение, доступ «Все» → скопировать ссылку /exec
3. В `index.html` вписать ссылку в `FORM_URL`

## Публикация на GitHub Pages
Settings → Pages → Branch: main, папка / (root) → Save. Через минуту сайт откроется по адресу
`https://<логин>.github.io/<репозиторий>/`

Технологии: HTML, CSS, JavaScript, Google Apps Script, Telegram Bot API
